# 🏠 Smart Home Skill — ระบบสั่งการบ้านอัจฉริยะด้วยเสียง (Tuya Smart IR)

สกิลนี้ช่วยให้มายมิ้นท์สามารถควบคุมเครื่องปรับอากาศและอุปกรณ์ภายในบ้านของบอส ผ่านคำสั่งเสียงและการสนทนาภาษาไทยได้อย่างลื่นไหล แม่นยำ และปลอดภัย

---

## ❄️ 1. อุปกรณ์หลักในบ้าน (Primary Device)

* **แอร์หลัก:** `Air (แอร์จริงในบ้าน)`
* **Device ID:** `a35a4e0b12b02aa750ceh4`
* **พอร์ต Gateway:** `http://localhost:3000` (Node.js Tuya Smart IR Microservice)
* **ช่วงอุณหภูมิที่รองรับ:** `16°C - 30°C`
* **โหมดที่รองรับ:** `cool` (ทำความเย็น), `auto` (อัตโนมัติ), `fan` (พัดลม), `dry` (ลดความชื้น)
* **แรงลมที่รองรับ:** `auto`, `low`, `medium`, `high`

---

## 🎯 2. แมปปิ้งคำสั่งเสียงเป็น Tools (Voice Intent Mapping)

### ก. การเปิด-ปิดแอร์
* *"มาย เปิดแอร์หน่อย"* / *"เปิดแอร์ให้ที"*
  -> เรียก `smart_home_control_ac(power=True)`
* *"มาย ปิดแอร์หน่อย"* / *"ปิดแอร์เลยนะ"*
  -> เรียก `smart_home_control_ac(power=False)`

### ข. การปรับอุณหภูมิ
* *"มาย ปรับแอร์เป็น 24 องศา"* / *"ตั้งแอร์ 25"*
  -> เรียก `smart_home_control_ac(temperature=24)`
* *"มาย แอร์ร้อนจัง ปรับให้เย็นขึ้นหน่อย"*
  -> เรียก `smart_home_get_ac_status()` ก่อน แล้วลดอุณหภูมิลง 1-2 องศา เช่น `smart_home_control_ac(temperature=current-1)`
* *"มาย แอร์หนาวจัง เพิ่มอุณหภูมิหน่อย"*
  -> เรียก `smart_home_get_ac_status()` ก่อน แล้วเพิ่มอุณหภูมิ 1 องศา

### ค. การตรวจสอบสถานะ
* *"มาย ตอนนี้แอร์เปิดอยู่ไหม / กี่องศา"*
  -> เรียก `smart_home_get_ac_status()`

### ง. การสั่งฉากอัตโนมัติ (Automation Scenes)
* *"มาย บอสจะนอนแล้วนะ / โหมดนอนหลับ"*
  -> เรียก `smart_home_trigger_scene(scene_id="scene-eco-sleep")`
* *"มาย โหมดดูหนัง / เปิดโรงหนัง"*
  -> เรียก `smart_home_trigger_scene(scene_id="scene-movie-night")`
* *"มาย บอสจะออกจากบ้านแล้วนะ"*
  -> เรียก `smart_home_trigger_scene(scene_id="scene-leave-home")`
